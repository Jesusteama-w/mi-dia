# Mi día

App personal para organizar el día: calendario, alarmas, cronograma, libreta, colegio, finanzas y música, con estética cristiana editorial.

- `app/`: la app web (HTML, CSS y JS sin compilación). Se publica sola en GitHub Pages.
- Los datos viven en Supabase, protegidos con login. Este repositorio no tiene datos personales ni claves secretas.
- Para probar en la PC: `python servidor.py` y abrir http://localhost:5173
